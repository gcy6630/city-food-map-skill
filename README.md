# city-food-map · 城市美食打卡地图

给一个城市名，产出一张**手机上能点、永久在线、可扫码**的美食地图。

```
抖音搜关键词 + 抓评论区  →  从评论里挖出本地人反复提的店  →  高德定位取评分/地址/招牌
        →  生成桌面版 + 手机版 HTML + Markdown 清单 + 手机速查 TXT
        →  传到 GitHub Pages（永久链接，微信里能直接开）  →  生成二维码
```

## 成品长什么样

两个真实成品（手机打开）：

- 连云港 · 46 家店 → https://gcy6630.github.io/lianyungang-food-map/
- 徐州 · 41 家店 → https://gcy6630.github.io/xuzhou-food-map/

手机版打开会**自动框住所有店**，顶部按分类筛选，底部抽屉是清单；**点任意一家，地图直接飞过去并弹出详情**，里面有"导航过去"按钮一键跳高德。

## 为什么不是"随便标几个店"

- **店名来自评论区**，不是探店视频里的广告位——评论区里本地人反复提的才是真的
- **高德查不到的店一律不标**，列进"评论区点名但高德搜不到"清单让用户自己确认，**不编店名**
- **同品牌选最火的那家分店**，不是随便挑
- 地图上还会写清"为什么推荐"（来源 + 原始评论）

## 两道强制闸门（这个技能的价值所在）

从别的城市复制模板是最容易出事的地方（作者本人就被用户当场抓包过：地图打开停在上一个城市、分类筛选按钮白底白字、点列表没反应）。所以：

| 闸门 | 干什么 |
|---|---|
| `city_lint.js` | 城市串味自检：禁用词、`background:undefined`、地图中心是否落在本城范围内、分类缺配色 |
| `verify_mobile.js` | 真交互验收：真的去点清单里的卡片，断言标记落在视野里、弹窗弹出、清单收起、0 报错 |

**只数标记数量是抓不出这类 bug 的**——数量全对、功能全错也能溜过去。

## 安装

见 [INSTALL.md](INSTALL.md)。最简单：把文件夹丢进 AionUi 的技能目录，然后

```powershell
'{"skill_path":"<绝对路径>\\city-food-map"}' | & $AIONUI_HELPER_BIN config skills import
```

## 需要注意

- 高德官方 API 的 **QPS 限得很死**，连发 4 个就报 `CUQPS_HAS_EXCEEDED_THE_LIMIT`。脚本里间隔 1.4 秒，**别调小**。
- 没高德 key 也能跑（`amap_scrape.js` 蹭网页版），但**会被 IP 级封 25~40 分钟**，且跳过冷却毫无意义。
- `*.github.io` 在**微信内置浏览器能正常打开**——这是选 GitHub Pages 而不是图床的核心理由。
- 抖音抓取需要登录态，且抖音风控会变；这部分是整套流程里最脆的一环。
